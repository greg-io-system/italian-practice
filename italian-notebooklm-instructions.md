# How to Use These Files with NotebookLM

## Quick Setup (5 minutes)

1. Go to https://notebooklm.google.com
2. Click "New Notebook"
3. Upload all four markdown files as sources:
   - italian-notebooklm-numbers.md
   - italian-notebooklm-cafe-restaurant.md
   - italian-notebooklm-getting-around.md
   - italian-notebooklm-shopping-markets.md
4. Once uploaded, go to Notebook Settings (gear icon) and set Output Language to Italian (or leave as English for a bilingual overview)

## Generating Audio Overviews

### Option A: Bilingual Learning Podcast (Recommended for beginners)
- Leave the output language as English
- Click "Generate" on Audio Overview
- Add this customization prompt: "Create a conversational podcast where two hosts walk through real Italian travel situations. For each phrase, say it first in English, then slowly and clearly in Italian, then use it in a mini-dialogue. Focus on the most practical phrases someone would need in their first week in Italy. Make it feel like two friends coaching a buddy before their trip."

### Option B: Full Italian Immersion
- Set output language to Italian
- Click "Generate" on Audio Overview
- Add this customization prompt: "Crea un podcast dove due presentatori parlano lentamente e chiaramente delle situazioni di viaggio in Italia. Usa frasi semplici e ripeti le parole chiave più volte. Includi mini-dialoghi tra un turista e un italiano."

### Option C: Numbers Drill Focus
- Select ONLY the numbers document as the source
- Generate an Audio Overview with this prompt: "Create a number drilling podcast. Start with 1-20, then tens to 100, then practice numbers in context: prices, times, quantities. Say each number slowly, pause for the listener to repeat, then use it in a real sentence. Make it interactive — quiz the listener on numbers they've heard."

## Suggested Learning Schedule (2 Weeks to Trip)

### Days 1-3: Foundation
- Listen to Numbers drill audio overview 2x daily (morning + evening)
- Use the interactive HTML app for number practice
- Goal: instant recall of numbers 1-100

### Days 4-7: Café & Restaurant
- Generate and listen to café/restaurant audio overview
- Practice ordering scenarios in the HTML app
- Goal: comfortable ordering coffee and a meal

### Days 8-10: Getting Around
- Generate and listen to transport audio overview
- Practice ticket-buying and direction scenarios
- Goal: navigate trains, taxis, and ask for directions

### Days 11-14: Shopping + Review
- Generate and listen to shopping/markets audio overview
- Mix all scenarios in the HTML app
- Generate a "final review" audio overview using all four sources
- Goal: handle any common travel situation with basic confidence

## Tips for Getting the Most Out of NotebookLM

1. Generate multiple audio overviews from the same sources with different prompts — you'll get different conversations each time, reinforcing vocabulary through varied contexts
2. Listen during commutes, workouts, or while cooking
3. After listening, test yourself with the interactive HTML app
4. Re-generate with harder prompts as you improve: "Assume the listener knows basic greetings and numbers. Focus on more complex situations and natural conversation flow."
